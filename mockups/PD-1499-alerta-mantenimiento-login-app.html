La trampa escenario = 500

En login, escenario: 500 está reservado para contraseña incorrecta: dispara un diálogo con botón de restablecer clave.

El JSON que lo genera

POST /api/auth/iniciar_sesion → HTTP 422 
{
  "titulo":    "Estamos en mantenimiento",
  "message":   "No podrás iniciar sesión hasta las 7:15 a. m. del jueves 30 de julio. Si ya realizaste un pago, quedó registrado.",
  "escenario": 200   // ← cualquier valor MENOS 500
}
!

El valor de escenario es lo único delicado. Ambas pantallas de login evalúan escenario == '500' y, si coincide, arman a mano un diálogo con el botón “Restablecer contraseña”. Cualquier otro valor cae al helper genérico, que es el que queremos.

Se usa 200 por consistencia: es el mismo valor que ya devuelve el middleware para el bloqueo “Aún no cuentas con cupo”.

Contrato de campos

CampoObligatorioQué hace en la app
titulo Sí Título del diálogo. Se muestra tal cual, sin transformar. Mantenerlo corto: una línea.
message Sí Cuerpo del diálogo. Si se alarga demasiado el diálogo se vuelve scrollable y pierde legibilidad; 2 o 3 líneas es el punto justo.
escenario Sí Enruta el tipo de diálogo. Debe ser distinto de 500. Si se omite, Flutter evalúa null y también funciona, pero conviene enviarlo explícito.
