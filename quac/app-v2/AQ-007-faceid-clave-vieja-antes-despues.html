La regla del ajuste

  1. Si el api rechaza la clave en un ingreso con Face ID, la clave guardada quedó vieja: la app la borra y Face ID queda apagado en ese teléfono.
  2. El cliente ve «Tu clave cambió. Ingresa con la nueva.» en vez del modal de error, escribe la clave nueva y puede volver a activar Face ID con el botón de al lado.
  3. Si la clave mala la escribió el cliente, nada cambia: modal de siempre y Face ID sigue activo.

Solo cambia la app. El api no cambia.

Alcance

Arregla a quien tiene Face ID activo en un teléfono y cambia o restablece la clave desde otro. Hoy ese teléfono reenvía la clave vieja en cada intento y cada uno cuenta para el bloqueo de la cuenta (5 fallos sumando todos los teléfonos). Con el ajuste falla una sola vez y no vuelve a mandarla.

No se puede contar a cuántos afecta: la 4.1.0 aún no está en tiendas. La 4.0.1 de tiendas tiene otro login y no se revisó aquí. Fuera del ajuste: el aviso para ofrecer Face ID justo después de entrar (hoy solo sale tras el registro).
